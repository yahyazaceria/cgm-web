## Project Description
The CGM Web Dashboard provides a secure, user-friendly interface for real-time visualization of glucose measurements from the non-invasive glucose monitoring device. This repository includes all frontend components, backend APIs, user authentication, and data visualization features.

---
## Main Features
- **Real-time Data Visualization**
  - Interactive glucose monitoring dashboards.
  - Historical data analysis with visual charts.

- **Secure User Authentication**
  - User registration and login functionality.
  - Secure profile and settings management.

- **Backend API Integration**
  - Real-time data fetching from CGM hardware.
  - Robust API endpoints for frontend integration.
